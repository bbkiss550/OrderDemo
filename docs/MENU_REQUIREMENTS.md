# เมนูอาหารและหมวดหมู่

แหล่งอ้างอิง: CODEX_HANDOFF.md และ screenshots/21–25 ใน FoodFlow_QuickOrder_V2_Codex

ผู้ใช้ยืนยัน 8 ตุลาคม 2026: **กำหนดเมนูแยกตามแพ็กเกจ** และปรับเป็น Standard/Deluxe/Premium แต่ละแพ็กเกจรวมราคาผู้ใหญ่/เด็ก บิลละหนึ่งแพ็กเกจ

พัฒนาแล้ว:

- หน้าหมวดหมู่: เพิ่ม/แก้ไขชื่อ ลำดับ และเปิด–ปิด
- หน้าอาหาร: เพิ่ม/แก้ไขชื่อ หมวดหมู่ คำอธิบาย Emoji ลำดับ สถานะขาย และรูป
- อาหารมีสวิตช์แยกแต่ละแพ็กเกจ เปิดหลายแพ็กเกจได้ ปิดทุกแพ็กเกจได้เพื่อเก็บอาหารที่ยังไม่พร้อมขาย
- รายการและรูปเก็บใน PostgreSQL ไม่ใช้ LocalStorage และไม่ผูกกับ filesystem ของ container
- ปิดหมวดหมู่ทำให้อาหารทั้งหมวดไม่พร้อมขาย โดยคงสถานะขายรายเมนูไว้
- สวิตช์ปิดอาหารชั่วคราว เช่น วัตถุดิบหมด; เปิดใหม่ได้
- ค้นหา debounce+clear และตัวกรองหมวดหมู่/แพ็กเกจ URL ไม่มี query parameters
- CRUD ผ่าน Modal/AJAX พร้อมตรวจ version ป้องกันการบันทึกทับข้อมูลที่เพิ่งถูกแก้ไข
- รูป JPG/PNG ไม่เกิน 2 MB ตรวจชนิดจากเนื้อไฟล์และขนาดภาพก่อนบันทึก
- ไม่มีการลบเมนู/หมวดหมู่ถาวรในหน้าจอ ใช้เปิด–ปิดเพื่อเก็บรายการไว้

ระยะนี้จัดการสิทธิ์อาหารในแอดมินแล้ว บิลใหม่มี package_id เดียว การตรวจสิทธิ์เมื่อส่งออเดอร์จะอิงแพ็กเกจประจำบิลในงานหน้าลูกค้า/ครัว ไม่ได้อ้างว่าระบบรับออเดอร์อาหารเปิดใช้งานแล้ว
